# GSE122897 Dataset Information

## ✅ Dataset Successfully Added to Project

**Accession:** GSE122897  
**Title:** RNA Sequencing Analysis of Intracranial Aneurysm Walls Reveals Involvement of Lysosomes and Immunoglobulins in Rupture  
**Organism:** Homo sapiens (Human)  
**Type:** Bulk RNA-seq (Expression profiling by high throughput sequencing)

## ⭐ KEY FEATURE: Ruptured vs Unruptured Comparison

**This dataset is HIGHLY VALUABLE because it:**
- ✅ Directly compares **ruptured vs unruptured** aneurysms
- ✅ Identifies rupture-specific gene expression patterns
- ✅ Focuses on rupture-associated pathways (lysosomes, immunoglobulins)
- ✅ Directly addresses the project's goal: rupture prediction

## 📁 Files Downloaded (4 files, ~12.0 MB)

### Expression Data Files:

1. **GSE122897_readCounts_raw.txt.gz** (2.00 MB)
   - Raw read counts
   - Use for: Differential expression analysis

2. **GSE122897_raw_counts_GRCh38.p13_NCBI.tsv.gz** (2.10 MB)
   - Raw gene counts (GRCh38.p13 reference)
   - Use for: Statistical modeling, differential expression

3. **GSE122897_norm_counts_TPM_GRCh38.p13_NCBI.tsv.gz** (3.89 MB)
   - TPM (Transcripts Per Million) normalized expression
   - Use for: Cross-sample comparisons, visualization

4. **GSE122897_norm_counts_FPKM_GRCh38.p13_NCBI.tsv.gz** (3.91 MB)
   - FPKM (Fragments Per Kilobase Million) normalized expression
   - Use for: Alternative normalization for comparisons
